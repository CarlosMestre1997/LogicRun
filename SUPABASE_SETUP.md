# Supabase Leaderboard Setup Guide

This guide will help you set up a global leaderboard using Supabase for your Startie game.

## Step 1: Create a Supabase Account and Project

1. Go to https://supabase.com
2. Sign up for a free account (if you don't have one)
3. Click "New Project"
4. Fill in:
   - **Name**: `startie-leaderboard` (or any name you prefer)
   - **Database Password**: Choose a strong password (save it somewhere safe)
   - **Region**: Choose the closest region to your users
5. Click "Create new project" (this takes a few minutes)

## Step 2: Get Your API Keys

1. In your Supabase project dashboard, go to **Settings** (gear icon) → **API**
2. You'll need:
   - **Project URL** (looks like: `https://xxxxxxxxxxxxx.supabase.co`)
   - **anon/public key** (under "Project API keys", the `anon` `public` key)
   - **service_role key** (keep this SECRET - only use for admin operations if needed)

## Step 3: Create the Database Table

The easiest way to create the table with proper auto-increment is using SQL. Here's how:

1. In your Supabase dashboard, go to **SQL Editor**
2. Click **"New query"**
3. Copy and paste this SQL code:

```sql
CREATE TABLE leaderboard (
  id BIGSERIAL PRIMARY KEY,
  code TEXT NOT NULL,
  score BIGINT NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

4. Click **"Run"** (or press Ctrl+Enter)

This will create the table with:
- `id`: Auto-incrementing primary key (BIGSERIAL = BIGINT + auto-increment sequence)
- `code`: Text field for the 3-letter code
- `score`: Big integer for the score
- `created_at`: Timestamp that automatically sets to current time
- `updated_at`: Timestamp that automatically sets to current time

**Alternative: Using Table Editor**

If you prefer using the Table Editor:
1. Go to **Table Editor** → Click **"New table"**
2. Name it: `leaderboard`
3. Add columns manually, but for the `id` column:
   - Type: `int8` or `bigint`
   - Check **"Is Primary Key"**
   - Leave Default Value empty (we'll set it via SQL)
4. Add other columns: `code` (text), `score` (int8), `created_at` (timestamptz), `updated_at` (timestamptz)
5. Click **"Save"**
6. Then go to **SQL Editor** and run:

```sql
-- Make id auto-increment (if table was created via Table Editor)
ALTER TABLE leaderboard 
ALTER COLUMN id ADD GENERATED BY DEFAULT AS IDENTITY;
```

**Note:** The SQL method is recommended as it sets everything up correctly in one step.

## Step 4: Set Up Row Level Security (RLS)

1. In the **Table Editor**, click on your `leaderboard` table
2. Click the **"Policies"** tab
3. Click **"New Policy"**
4. For **SELECT (read)**:
   - Policy name: `allow public read`
   - Policy Command: Select **SELECT**
   - Target Roles: Leave as `public` (default)
   - In the SQL snippet field under "using", enter: `true`
   - Click **"Review"** then **"Save policy"**

5. Click **"New Policy"** again
6. For **INSERT (write)**:
   - Policy name: `allow public insert`
   - Policy Command: Select **INSERT**
   - Target Roles: Leave as `public` (default)
   - In the SQL snippet field under "with check", enter: `true`
   - Click **"Review"** then **"Save policy"**

**Note:** The SQL expression `true` means "allow for all rows" - this allows anyone to read and insert into the leaderboard table.

## Step 5: Create an Index (Optional but Recommended)

1. In Supabase dashboard, go to **SQL Editor**
2. Run this SQL to create an index for faster queries:

```sql
CREATE INDEX idx_leaderboard_score ON leaderboard(score DESC);
```

3. Click **"Run"**

## Step 6: Configure Your Project

1. Copy `config.js.example` to `config.js`:
   ```bash
   cp config.js.example config.js
   ```
   (Or manually create `config.js` from the example file)

2. Open `config.js` and replace the placeholder values with your actual Supabase credentials:
   - Replace `https://your-project-id.supabase.co` with your **Project URL**
   - Replace `your-anon-key-here` with your **anon public key**

3. The `.gitignore` file has been created to keep `config.js` out of git (to protect your keys)

## Step 7: Add Supabase Script to HTML

You need to add the Supabase JavaScript client library to your HTML. 

**Add this script tag to the `<head>` section of `highscores.html`** (before the closing `</head>` tag):

```html
<script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
```

**Important:** This script must load BEFORE your module scripts.

## Step 8: Switch to Supabase Version

After completing steps 1-7, you'll need to update `highscores.html` to use the Supabase version:

1. Change the import from:
   ```javascript
   import { getCumulativeLeaderboard, saveCumulativeScore, getCurrentRunTotal, resetRunTotal } from './utils/leaderboard.js';
   ```
   To:
   ```javascript
   import { getCumulativeLeaderboard, saveCumulativeScore, getCurrentRunTotal, resetRunTotal } from './utils/leaderboard-supabase.js';
   ```

2. Make the functions async (they'll return Promises now). Update `updateLeaderboard()` and the submit handler to use `await`.

See the example code below for the updated version.

## Example: Updated highscores.html Code

Here's what the updated script section should look like:

```javascript
<script type="module">
// Add Supabase initialization
import { initSupabase } from './utils/supabase.js';
import { getCumulativeLeaderboard, saveCumulativeScore, getCurrentRunTotal, resetRunTotal } from './utils/leaderboard-supabase.js';
import { saveMusicPosition } from './utils/sounds.js';

// Initialize Supabase when page loads
initSupabase();

const scoreEntry = document.getElementById('score-entry');
const playerCodeInput = document.getElementById('player-code');
const submitScoreBtn = document.getElementById('submit-score');
const codeError = document.getElementById('code-error');
const totalScoreDisplay = document.getElementById('total-score-display');
const leaderboardList = document.getElementById('leaderboard-list');

// Get total score from URL parameter or localStorage
const urlParams = new URLSearchParams(window.location.search);
const totalScore = urlParams.get('score') ? parseInt(urlParams.get('score'), 10) : getCurrentRunTotal();

// Display total score
totalScoreDisplay.textContent = totalScore.toLocaleString();

// Show score entry if there's a score to submit
if (totalScore > 0) {
  scoreEntry.style.display = 'block';
}

// Update leaderboard display (now async)
async function updateLeaderboard() {
  const leaderboard = await getCumulativeLeaderboard();
  leaderboardList.innerHTML = '';
  
  if (leaderboard.length === 0) {
    leaderboardList.innerHTML = '<p style="color: #888;">No scores yet. Be the first!</p>';
    return;
  }
  
  leaderboard.forEach((entry, index) => {
    const entryDiv = document.createElement('div');
    entryDiv.style.cssText = 'display: flex; justify-content: space-between; padding: 8px 0; border-bottom: 1px solid #444;';
    entryDiv.innerHTML = `
      <span style="color: var(--white);">${entry.code}</span>
      <span style="color: var(--pink);">${entry.score.toLocaleString()}</span>
    `;
    leaderboardList.appendChild(entryDiv);
  });
}

// Submit score (now async)
submitScoreBtn.onclick = async () => {
  const code = playerCodeInput.value.trim().toUpperCase();
  codeError.textContent = '';
  
  if (code.length !== 3) {
    codeError.textContent = 'Code must be 3 characters';
    return;
  }
  
  if (!/^[A-Z0-9]{3}$/.test(code)) {
    codeError.textContent = 'Code must be letters or numbers only';
    return;
  }
  
  await saveCumulativeScore(code, totalScore);
  resetRunTotal();
  scoreEntry.style.display = 'none';
  await updateLeaderboard();
};

// ... rest of the code (keypress handlers, navigation, etc.) stays the same

// Initialize
updateLeaderboard();
</script>
```

## Testing

1. Open `highscores.html` in your browser
2. Open the browser console (F12) to check for any errors
3. Try submitting a score
4. The leaderboard should update with data from Supabase
5. If Supabase is unavailable, it will fall back to localStorage

## Troubleshooting

- **"Supabase client not loaded"**: Make sure the script tag is in the `<head>` section
- **"Supabase config not found"**: Make sure `config.js` exists and has valid values
- **RLS Policy errors**: Make sure you created both SELECT and INSERT policies
- **Network errors**: Check that your Supabase project URL and keys are correct
